# SocialSync

Social media scheduler for Buckalew Financial Services / AI Setup Pros: a React (Vite) UI, a Firebase sign-in and
data layer, and a Node/Express server that publishes to Facebook Pages, Instagram Business, LinkedIn (profile and
company Page) and X. It includes an encrypted token store and a built-in scheduler.

- Setup, developer apps and redirect URIs: see **SETUP.md**
- Config variable names: see **.env.example**
- `npm ci && npm run build`, then `npm start` (production) or `npm run dev`
- `npm test` / `npm run typecheck` / `npm run dry-run`
